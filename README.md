# Nudge prototype

A clickable prototype of Nudge, a proposed Evernote satellite app, made for a design task.
Designed in Figma by Julio Carvalho, built with AI assistance (Claude Code). Best on a phone.

Live: https://juliostc.github.io/nudge-prototype/

This repo holds the built site only.
